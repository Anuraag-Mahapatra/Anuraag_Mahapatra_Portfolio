# Anuraag Mahapatra - Personal Portfolio

A sleek, responsive, single-page portfolio website built to showcase my projects, skills, and journey from Electrical Engineering to Full-Stack Web Development. 

## 🚀 Overview

This portfolio is built with **Vanilla HTML, CSS, and JavaScript**, focusing on clean design, smooth animations, and responsive layouts without relying on heavy frameworks. 

### Key Features
*   **Responsive Design:** Fully fluid layout using CSS Grid and Flexbox, ensuring a great experience on mobile, tablet, and desktop.
*   **Custom UI/UX:** Unique schematic trace animations, glassmorphism navigation, and custom CSS variables for a consistent engineering-themed color palette.
*   **Project Showcase:** Dedicated sections for highlighting full-stack projects, including GitHub links and tech stack tags.
*   **Intersection Observer:** Dynamic active navigation highlighting as the user scrolls through the page.

## 🛠️ My Tech Stack

While this portfolio is built with vanilla web technologies, my primary development stack includes:

*   **Front-End:** React.js, Tailwind CSS, HTML5, CSS3, JavaScript (ES6+)
*   **Back-End:** Node.js, Express.js, REST APIs, JWT Authentication
*   **Database:** MongoDB, MongoDB Compass, Schema Design
*   **Languages:** JavaScript, Python, Java
*   **Tools:** Git, GitHub, VS Code, npm

## 💻 Featured Projects

Here are some of the key projects featured on this portfolio:

1.  **Zairzest 4.0 Website:** Built 2 of 6 pages for the official tech fest website of Zairza Technical Society (OUTR) working in a team of 3.
2.  **Event Booking System:** A full-stack REST API for event booking with JWT-based stateless authentication and MongoDB.
3.  **TODO List Application:** A highly optimized React-based task manager handling 500+ records with local storage persistence.

## 🚀 Running Locally

To view the portfolio locally, simply clone the repository and open the HTML file in your browser:

```bash
# Clone the repository
git clone https://github.com/Anuraag-Mahapatra/portfolio-website.git

# Navigate to the project directory
cd portfolio-website

# Open index.html in your default web browser
```
